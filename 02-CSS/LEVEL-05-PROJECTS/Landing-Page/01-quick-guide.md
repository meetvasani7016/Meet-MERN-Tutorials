# Landing Page Hero

## In One Line
A landing hero section introduces a product and gets users to click an action button.

## Think Like This
A billboard next to a highway that has a big catchphrase and a website address.

## Example
```css
.hero { display: flex; align-items: center; min-height: 100vh; }
```

## Result
A fullscreen area centering headline texts and buttons.

## Remember
Clear sizing and call-to-action buttons make landing sections successful.
