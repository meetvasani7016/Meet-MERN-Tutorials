# Responsive Design

## In One Line
Responsive design ensures websites adapt and render beautifully across phones, tablets, and computers.

## Think Like This
Water flowing into containers.

A responsive page flows smoothly to fit a narrow glass cylinder (mobile screen) or a wide shallow bowl (desktop monitor).

## Example
```html
.page {
  width: 90%;
  max-width: 1200px;
  margin: 0 auto;
}
```

## Result
Stretches container to fit narrow screens but limits growth to 1200px on wider displays.

## Remember
Always build mobile-first: design layouts for small screens first, then expand for desktop screens.
