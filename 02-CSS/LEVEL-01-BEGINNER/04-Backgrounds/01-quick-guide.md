# CSS Backgrounds

## In One Line
Background properties add colors, image patterns, or gradients behind elements.

## Think Like This
Backgrounds are like painting a room's wall a solid color, or hanging a patterned wallpaper.

## Example
```html
div {
  background-color: lightblue;
}
```

## Result
Turns the background of the div block solid light blue.

## Remember
Use background-size: cover; to make background images stretch to fit containers without distortion.
