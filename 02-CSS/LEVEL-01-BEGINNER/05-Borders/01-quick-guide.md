# CSS Borders

## In One Line
Borders draw boundary frames around HTML elements.

## Think Like This
Borders are picture frames.

You can set a solid black frame, a dotted red frame, and round the frame corners using border-radius.

## Example
```html
div {
  border: 2px solid black;
  border-radius: 8px;
}
```

## Result
Renders a black boundary line with smooth rounded corners.

## Remember
Use border-radius: 50% on a square element to make it a perfect circle!
