# CSS Colors

## In One Line
CSS styles text and backgrounds using color names, Hex codes, RGB, or HSL values.

## Think Like This
Colors are paints on a palette.

- Name color: simple color names like 'red' or 'blue'.
- RGB mixer: values from 0-255 representing red, green, and blue light.
- Hex code: code shortcut representing RGB values.

## Example
```html
h1 {
  color: #ff5733;
}
```

## Result
Turns the heading text into a vibrant coral/orange shade.

## Remember
Color handles text colors, while background-color handles behind-text background fills.
