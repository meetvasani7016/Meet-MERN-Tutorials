# CSS Introduction

## In One Line
CSS (Cascading Style Sheets) is the language used to design the look and layout of a webpage.

## Think Like This
If HTML is the wooden skeleton/bricks of a house, CSS is the wall paint, floor tiles, and wallpaper decor.

## Example
```html
h1 {
  color: blue;
  font-size: 24px;
}
```

## Result
Turns all `<h1>` headings blue and increases their text font size.

## Remember
HTML structures content. CSS designs look. Always separate your styles from your HTML structure!
