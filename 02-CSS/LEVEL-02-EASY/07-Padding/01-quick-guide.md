# CSS Padding

## In One Line
Padding creates empty spacing INSIDE an element's border, pushing content from the edge.

## Think Like This
Padding is bubble wrap cushioning inside a box.

It protects the items inside from scraping directly against the hard box borders.

## Example
```html
button {
  padding: 10px 20px;
}
```

## Result
Adds 10px spacing top/bottom and 20px left/right inside the button's border.

## Remember
Padding increases the clickable size of buttons and link tags, improving usability on mobile screens.
