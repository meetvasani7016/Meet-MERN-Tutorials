# CSS Margins

## In One Line
Margins create spacing OUTSIDE of an element's border, pushing neighbor items away.

## Think Like This
Margins are your personal bubble.

You push adjacent objects away to create clear empty spacing around your outside edges.

## Example
```html
div {
  margin: 20px;
}
```

## Result
Pushes all surrounding boxes 20 pixels away on all sides.

## Remember
margin: 0 auto; is a trick used to center block elements horizontally inside their parent.
