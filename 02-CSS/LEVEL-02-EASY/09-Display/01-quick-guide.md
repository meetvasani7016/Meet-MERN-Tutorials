# CSS Display

## In One Line
Display controls how an element behaves in the document layout flow.

## Think Like This
Block elements are bricks: they stack vertically. Inline elements are words in a text line: they sit side-by-side.

## Example
```html
span {
  display: block;
}
```

## Result
Makes a span behave like a div, taking up the full width and breaking to a new line.

## Remember
display: none hides an element completely. Unlike visibility: hidden, it releases its space in the layout layout.
