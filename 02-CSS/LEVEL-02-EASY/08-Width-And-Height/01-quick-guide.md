# CSS Width and Height

## In One Line
Width and height define the sizing dimensions of block elements.

## Think Like This
Sizing a poster frame to hang on a wall.

You can size it in exact pixels (px) or make it a percentage width of the parent wall (%).

## Example
```html
div {
  width: 50%;
  height: 200px;
}
```

## Result
Makes the container half as wide as the screen, and 200 pixels tall.

## Remember
Always use max-width: 100% on images so they resize cleanly instead of overflowing phone screens.
