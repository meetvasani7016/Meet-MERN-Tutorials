# Tailwind CSS Spacing

## In One Line
Utilities to adjust margins, paddings, and flex/grid gaps in increments.

## Think Like This
Adding spacing tabs on a layout ruler to keep element blocks from overlapping or sticking together.

## Example
```html
<div class="p-4 m-2 gap-4">...</div>
```

## Result
Applies 1rem padding, 0.5rem margin, and 1rem gap spacing.

## Remember
Tailwind spacing numbers represent increments of 0.25rem (e.g. p-4 is 1rem / 16px).
