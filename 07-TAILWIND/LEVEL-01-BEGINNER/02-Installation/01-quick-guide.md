# Tailwind CSS Installation

## In One Line
Teach both CDN (quick testing) and Vite CLI (professional build setup) approaches to run Tailwind CSS.

## Think Like This
Vending machine snacks (CDN, instant but heavy) vs shopping for fresh ingredients to cook a customized light meal (Vite CLI compilation).

## Example
```html
CDN link script vs npm install and configuration.
```

## Result
Prepares workspaces for responsive CSS utility compile runs.

## Remember
The CLI compilation scans your code and strips out unused classes, leaving a lightweight production CSS bundle.
