# Tailwind CSS Typography

## In One Line
Utility classes for font sizing, weight, family, line height, and text alignment.

## Think Like This
Adjusting text settings in Word: choosing headline size, bolding titles, adjusting paragraph height.

## Example
```html
<h1 class="text-3xl font-extrabold tracking-tight text-gray-900">Title</h1>
```

## Result
Renders a bold, tightly-spaced heading.

## Remember
Use tracking utilities (e.g. tracking-tight) on headings for a premium, editorial design aesthetic.
