# Tailwind CSS Pricing Card

## In One Line
Build a beautiful, responsive three-tier pricing card page grid with shadows, hover transitions, and clean badge highlights.

## Think Like This
Organizing a pricing sheet: create border-separated grids, highlight the 'best seller' package (scale, vibrant button), and display list tags.

## Example
```html
<div class="grid grid-cols-1 md:grid-cols-3 gap-6">...</div>
```

## Result
Renders a premium subscription card page.

## Remember
Using font tracking (tracking-tight) and shadows (shadow-xl) makes layouts look professional.
