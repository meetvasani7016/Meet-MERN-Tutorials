# Tailwind CSS Sizing

## In One Line
Utility classes to control the width and height of element containers.

## Think Like This
Stretching box boundaries: setting absolute pixel size limits, scaling width percentages, or setting height constraints.

## Example
```html
<div class="w-1/2 md:w-full h-64">...</div>
```

## Result
Renders a box half-screen wide on mobile and full-width on desktop, with fixed heights.

## Remember
Percentage widths use fractions (e.g. w-1/2, w-1/3, w-3/4). Full screens use w-screen/h-screen.
