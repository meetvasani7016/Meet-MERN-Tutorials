# Tailwind CSS Grid

## In One Line
Build two-dimensional responsive layouts with columns, rows, and gaps.

## Think Like This
A bento box container dividing items into distinct boxes with grids and span columns.

## Example
```html
<div class="grid grid-cols-3 gap-4"><div class="col-span-2">Main</div><div>Side</div></div>
```

## Result
Renders a 3-column layout where the main column spans 2 widths.

## Remember
Define column counts using class grid-cols-[1-12], then control spans using col-span-[1-12] on children.
