# Tailwind CSS Dark Mode

## In One Line
Style alternative color themes using the dark: media utility selector prefix.

## Think Like This
Flipping a light switch. Elements labeled with 'dark:' instructions activate when dark mode is enabled.

## Example
```html
<div class="bg-white dark:bg-gray-900 text-gray-900 dark:text-white">Theme Card</div>
```

## Result
Renders dark themes on computers configured for dark mode or containing class dark.

## Remember
Tailwind supports both media queries (system settings) and class toggles to enable dark mode.
