# Tailwind CSS Hover States

## In One Line
Trigger styles dynamically using interactive prefix states.

## Think Like This
Stick instructions stating 'if cursor is hovering, paint background darker green' or 'if focused, add shadow'.

## Example
```html
<button class="bg-blue-500 hover:bg-blue-600 focus:ring-4 focus:ring-blue-300">Click</button>
```

## Result
Adds interactive transitions and rings on hover and focus.

## Remember
Combine hover states with transition utilities (e.g. transition duration-200) for smooth page animations.
