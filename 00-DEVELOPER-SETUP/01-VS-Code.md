# 🛠️ Code Editor: Visual Studio Code

Visual Studio Code (VS Code) is the most popular, free, and lightweight code editor used by professional web developers worldwide.

## 📥 Installation

1.  **Download VS Code**: Go to [code.visualstudio.com](https://code.visualstudio.com/).
2.  **Select your Operating System**:
    *   **Windows**: Download the User Installer, run the `.exe`, and check the boxes for **"Add to PATH"** and **"Open with Code"**.
    *   **macOS**: Download the `.zip` file, unzip it, and drag the Visual Studio Code application into your **Applications** folder.
    *   **Linux**: Download the `.deb` (Debian/Ubuntu) or `.rpm` package and install it.

## 🧭 Interface Overview

When you open VS Code, you will see a clean screen split into key areas:

```text
+-----------------------------------------------------------------+
| (O) File  Edit  Selection  View  Go  Run  Terminal  Help         |
+---+-------------------------------------------------------------+
|   | EXPLORER                                                    |
| A |   > MeetTutorials                                           |
| C |     > 01-HTML                                               |
| T |       > LEVEL-01-BEGINNER                                   |
| I |         > 01-Introduction                                   |
| V |           - 01-quick-guide.md  <-- [ACTIVE EDITOR WINDOW]   |
| I |                                                             |
| T |                                                             |
| Y |                                                             |
|   |                                                             |
+---+-------------------------------------------------------------+
|   | TERMINAL (Ctrl+`)                                           |
|   | ps c:\projects\MeetTutorials> _                             |
+---+-------------------------------------------------------------+
```

1.  **Activity Bar (Far Left)**: Icons to switch views: Explorer (Files), Search, Source Control (Git), Run/Debug, and Extensions.
2.  **Sidebar (Left)**: Shows your active files, folders, and settings.
3.  **Editor Window (Center)**: Where you read and write your actual code.
4.  **Terminal (Bottom)**: Built-in command line where you can run Git commands and Node.js. Open it with `Ctrl + `` (or `Cmd + `` on Mac).

## 📁 How to Open a Project Folder

To start learning and writing code:
1.  Launch VS Code.
2.  Go to **File** -> **Open Folder** (on Mac: **File** -> **Open...**).
3.  Navigate to and select the `MeetTutorials` folder on your computer.
4.  Click **Select Folder**. You will now see all lessons in the left sidebar!
