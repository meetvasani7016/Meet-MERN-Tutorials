# 🔌 Recommended VS Code Extensions

Extensions add powerful new features, language support, and automation tools to VS Code, making your development workflow significantly faster and more enjoyable.

## 🏆 Top Extensions for Beginners

To install these, click the **Extensions** icon in the VS Code Sidebar, search for the extension name, and click **Install**.

### 1. Prettier - Code formatter (by Prettier)
*   **What it does**: Automatically cleans up and aligns your code syntax (spacing, quotes, line wraps) whenever you save.
*   **Why you need it**: Keeps your code looking clean and professional, and prevents syntax layout arguments.
*   **Configuration**: To make it format on save, go to **Settings** (Ctrl+, / Cmd+,), search for `"Format On Save"`, and check the checkbox.

### 2. Auto Rename Tag (by Jun Han)
*   **What it does**: When you rename an HTML tag (e.g., changing `<h1>` to `<h2>`), it automatically updates the corresponding closing tag (`</h1>` to `</h2>`) instantly.
*   **Why you need it**: Prevents mismatched tag syntax errors and saves time.

### 3. GitLens - Git supercharged (by GitKraken)
*   **What it does**: Displays unobtrusive text annotations next to the active code line, showing who committed that line, when, and with what commit message.
*   **Why you need it**: Helps you understand file history and changes at a glance.

### 4. Material Icon Theme (by Philipp Kief)
*   **What it does**: Replaces default VS Code file/folder icons with beautiful, colorful Material Design icons matching specific file types (HTML, CSS, JS, Git).
*   **Why you need it**: Makes your file explorer look premium and easy to scan.
