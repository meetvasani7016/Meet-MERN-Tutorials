# 🌐 Live Server Extension

When writing HTML and CSS, you want to see your changes instantly in the browser without manually refreshing the page. **Live Server** makes this possible.

## 📥 How to Install

1.  Open **VS Code**.
2.  Click the **Extensions** icon on the Activity Bar (looks like four blocks, or press `Ctrl+Shift+X` / `Cmd+Shift+X`).
3.  Search for **"Live Server"** (by Ritwick Dey).
4.  Click the blue **Install** button.

```text
+---------------------------------------------+
| EXTENSIONS                                  |
|  [ Live Server            ]  [ Install ]    |
|  by Ritwick Dey                             |
+---------------------------------------------+
```

## 🚀 How to Launch Live Server

Once installed:
1.  Open any `.html` file in your editor (for example, `01-HTML/LEVEL-01-BEGINNER/01-Introduction/02-example.html`).
2.  Look at the **Status Bar** at the bottom-right corner of VS Code.
3.  Click the **Go Live** button.
4.  Alternatively, **right-click** anywhere inside the editor window of the HTML file and select **Open with Live Server**.

```text
+-------------------------------------------------------+
|  Right-click menu:                                    |
|   Format Document                                     |
|   Change All Occurrences                              |
|   [ Open with Live Server ]  <-- Click this!          |
+-------------------------------------------------------+
```

## 🔄 Auto-Reload in Action

*   Live Server will automatically launch your default web browser and open the HTML page (usually at `http://127.0.0.1:5500/`).
*   Keep VS Code on one half of your screen and the browser on the other half.
*   Edit a heading in VS Code and press **Save (Ctrl+S)**.
*   Watch the browser update instantly without you clicking refresh!
