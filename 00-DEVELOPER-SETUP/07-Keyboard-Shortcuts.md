# ⌨️ Essential Keyboard Shortcuts

Learning keyboard shortcuts will double your coding speed. Instead of clicking menus or using the mouse, use these standard VS Code keyboard shortcuts.

## 💾 Core File Shortcuts

| Action | Windows / Linux | macOS |
| :--- | :--- | :--- |
| **Save File** (Run this constantly!) | `Ctrl + S` | `Cmd + S` |
| **Open File** | `Ctrl + O` | `Cmd + O` |
| **Close Editor Tab** | `Ctrl + W` | `Cmd + W` |
| **Open Settings** | `Ctrl + ,` | `Cmd + ,` |

## 📝 Code Editing Shortcuts

| Action | Windows / Linux | macOS |
| :--- | :--- | :--- |
| **Comment / Un-comment Line** | `Ctrl + /` | `Cmd + /` |
| **Copy Line Up / Down** | `Shift + Alt + Up/Down` | `Shift + Option + Up/Down` |
| **Move Line Up / Down** | `Alt + Up/Down` | `Option + Up/Down` |
| **Find Text in File** | `Ctrl + F` | `Cmd + F` |
| **Replace Text in File** | `Ctrl + H` | `Cmd + H` |
| **Select All Occurrences** | `Ctrl + Shift + L` | `Cmd + Shift + L` |

## 🖥️ Terminal & View Shortcuts

| Action | Windows / Linux | macOS |
| :--- | :--- | :--- |
| **Open Built-in Terminal** | `Ctrl + \` ` | `Cmd + \` ` |
| **Toggle Sidebar** | `Ctrl + B` | `Cmd + B` |
| **Open Command Palette** | `Ctrl + Shift + P` | `Cmd + Shift + P` |
| **Zoom In / Zoom Out** | `Ctrl + =` / `Ctrl + -` | `Cmd + =` / `Cmd + -` |
