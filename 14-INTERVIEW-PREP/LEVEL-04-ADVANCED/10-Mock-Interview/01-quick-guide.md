# Mock Interview Guide

## 1. What is it?
Step-by-step mock interview script and checklists for junior developers to practice technical communication.

## 2. Why do we use it?
To build communication confidence, practice speaking thoughts aloud while coding under pressure, and eliminate interview anxiety.

## 3. How does it work?
- **Analogy**: Simulating a real technical interview loop: coding aloud, explaining logic, and asking clarifying questions.
- **Mechanism**: The feature parses inputs or operations synchronously or asynchronously, executing compiled instructions and returning output responses or state modifications.

## 4. Where is it used?
Pre-interview warmups and pair practice sessions.

## 5. How do we build with it?
```json
Talking through a coding task: State inputs -> Outline logic -> Write code -> Test scenarios.
```

- **Expected Output**: Reduces interview anxiety through systematic preparation.
- **Best Practice / Rule**: Never code in silence during a live technical interview! Always speak your thoughts aloud.
