# What is Open Source

## 1. What is it?
Open Source is a software release model where code is publicly accessible, allowing anyone to view, modify, and distribute it.

## 2. Why do we use it?
To understand how publicly accessible repositories collaborate on shared code bases under specific legal licensing terms (like MIT or GPL).

## 3. How does it work?
- **Analogy**: A public library. Anyone can read, copy, study, and recommend edits to the books on the shelves.
- **Mechanism**: The feature parses inputs or operations synchronously or asynchronously, executing compiled instructions and returning output responses or state modifications.

## 4. Where is it used?
Understanding global software collaboration frameworks.

## 5. How do we build with it?
```sh
Linux, Node.js, Express, React, and Git are all open-source projects.
```

- **Expected Output**: Enables global collaboration and software quality scaling.
- **Best Practice / Rule**: Open source code must have a license (e.g. MIT, GPL) defining how it can be used.
