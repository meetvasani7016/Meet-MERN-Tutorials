# GitHub Issues

## 1. What is it?
Issues track bug reports, feature requests, and tasks inside GitHub repositories.

## 2. Why do we use it?
To write structured bug tickets detailing logs, reproduction steps, and system configurations for community discussion.

## 3. How does it work?
- **Analogy**: An office ticket box. Teammates write tickets describing bugs or proposals, assigning developers to resolve them.
- **Mechanism**: The feature parses inputs or operations synchronously or asynchronously, executing compiled instructions and returning output responses or state modifications.

## 4. Where is it used?
Collaborative tracking of bugs and features inside GitHub.

## 5. How do we build with it?
```sh
Creating an issue detailing a bug with steps to reproduce and system specs.
```

- **Expected Output**: Coordinates task lists and bug tracking workflows.
- **Best Practice / Rule**: Always check if a similar issue already exists before opening a new one.
