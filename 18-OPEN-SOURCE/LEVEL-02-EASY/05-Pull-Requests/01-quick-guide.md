# Pull Requests

## 1. What is it?
Pull Requests (PR) propose code modifications from your branch to the original upstream repository.

## 2. Why do we use it?
To propose your branch changes back to the upstream master repository, triggering automated tests and review cycles by maintainers.

## 3. How does it work?
- **Analogy**: Submitting an article edit to a newspaper editor. You submit your draft; the editor reviews and merges it.
- **Mechanism**: The feature parses inputs or operations synchronously or asynchronously, executing compiled instructions and returning output responses or state modifications.

## 4. Where is it used?
Submitting bug fixes and feature additions to public projects.

## 5. How do we build with it?
```sh
Creating a PR on GitHub to merge your bug-fix branch into the main repository branch.
```
