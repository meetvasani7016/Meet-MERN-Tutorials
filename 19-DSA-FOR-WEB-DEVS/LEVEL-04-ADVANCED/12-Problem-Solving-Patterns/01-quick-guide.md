# Problem Solving Patterns

## 1. What is it?
Problem Solving Patterns are algorithmic templates like Two Pointers or Sliding Window used to solve coding problems efficiently.

## 2. Why do we use it?
To apply templates (like Two Pointers or Sliding Window) to reduce nested loop overheads from O(N^2) to O(N) linear time.

## 3. How does it work?
- **Analogy**: Blueprint tactics. Instead of double-looping brute-force (O(N^2)), you use a pointer on each end (O(N)) to save cycles.
- **Mechanism**: The feature parses inputs or operations synchronously or asynchronously, executing compiled instructions and returning output responses or state modifications.

## 4. Where is it used?
Optimizing real-time analytics feeds and search parsing speeds.

## 5. How do we build with it?
```js
Two Pointers compares items from both ends. sliding Window tracks array subsets.
```

- **Expected Output**: Enables optimal coding interview solutions.
- **Best Practice / Rule**: Brute-force nested loops are often a red flag in coding interviews. Always think about O(N) alternatives.
