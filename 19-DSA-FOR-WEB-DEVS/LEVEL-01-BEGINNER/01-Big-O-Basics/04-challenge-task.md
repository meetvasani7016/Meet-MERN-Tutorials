# Challenge Task: Big O Complexity Analysis

## Objective
Analyze and compare the Time and Space complexity scaling of different solutions.

## Challenge Instructions
1. Open a JavaScript file and write a function that checks if a list (array) of elements contains any duplicate values.
2. Implement two different approaches:
   - **Approach A (Brute Force)**: Compare every element to every other element using nested loops.
   - **Approach B (Optimized)**: Use a Set or Object key lookup to find duplicates in a single pass.
3. Write comments above each function explaining:
   - The **Time Complexity** (Big O) of the function.
   - The **Space Complexity** (Big O) of the function.
   - Explain which approach performs better when processing an array containing 100,000 items, and why.
