# DSA Strings

## 1. What is it?
Strings are sequences of characters used to store and manipulate text data.

## 2. Why do we use it?
To validate, parse, and manipulate textual input strings efficiently, which is the baseline data format for web communication.

## 3. How does it work?
- **Analogy**: A string of alphabetical beads. Finding specific letters, reversing order, or splitting sections.
- **Mechanism**: The feature parses inputs or operations synchronously or asynchronously, executing compiled instructions and returning output responses or state modifications.

## 4. Where is it used?
Sanitizing search inputs, matching regex patterns, and parsing path strings.

## 5. How do we build with it?
```js
Reversing text using character pointers.
```

- **Expected Output**: Enables robust text parsing manipulations.
- **Best Practice / Rule**: In JavaScript, strings are immutable. Every string modification creates a new string in memory.
