# DSA Arrays

## 1. What is it?
Arrays are contiguous memory blocks storing collections of items indexed from 0.

## 2. Why do we use it?
To store linear lists of items efficiently and understand insertion/deletion cost boundaries in web layouts.

## 3. How does it work?
- **Analogy**: A row of numbered lockers. Accessing locker
- **Mechanism**: The feature parses inputs or operations synchronously or asynchronously, executing compiled instructions and returning output responses or state modifications.

## 4. Where is it used?
Rendering cart checkouts arrays and data tables.

## 5. How do we build with it?
```js
Inserting at front is O(N) shift; pushing to end is O(1) push.
```

- **Expected Output**: Enables linear data listings operations.
- **Best Practice / Rule**: Array access is fast, but inserting or deleting elements in the middle/front is slow.
