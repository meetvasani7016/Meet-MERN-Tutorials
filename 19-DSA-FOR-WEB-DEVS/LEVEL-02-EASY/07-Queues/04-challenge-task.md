# Challenge Task: Implement Queue using Stacks

## Objective
Replicate Queue (FIFO) behavior using only Stack (LIFO) inputs.

## Challenge Instructions
1. Define a class `QueueUsingStacks` that simulates a First-In, First-Out queue using only two standard Stacks (arrays where you only call `push()` and `pop()`).
2. The class should expose:
   - `enqueue(item)`: Adds an item to the queue.
   - `dequeue()`: Removes and returns the front item of the queue.
   - `peek()`: Returns the front item without removing it.
   - `isEmpty()`: Returns true if the queue contains no elements.
3. Add comments explaining the Time Complexity of both the enqueue and dequeue operations in your class.
