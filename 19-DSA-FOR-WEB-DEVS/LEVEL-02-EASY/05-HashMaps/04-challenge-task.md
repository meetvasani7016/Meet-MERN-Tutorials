# Challenge Task: Two Sum using Map

## Objective
Solve the classic Two Sum search problem in linear time using the properties of a JS Map.

## Challenge Instructions
1. Write a function `twoSum(nums, target)` that searches an array of numbers to locate the indices of two elements that add up exactly to the target value.
2. Assume that each input array contains exactly one solution, and you cannot use the same element index twice.
3. Instead of a nested loop brute-force search running in O(N^2) time, implement the search in **O(N) time** using a `new Map()` to store visited numbers and their index positions.
