# DSA HashMaps

## 1. What is it?
HashMaps are dictionary structures mapping keys to array indices using hashing functions.

## 2. Why do we use it?
To map arbitrary key objects to values efficiently, preserving insertion order and supporting non-string key fields.

## 3. How does it work?
- **Analogy**: Locker key allocation: a name is hashed into a locker number, where your belongings are stored.
- **Mechanism**: The feature parses inputs or operations synchronously or asynchronously, executing compiled instructions and returning output responses or state modifications.

## 4. Where is it used?
Router mappings, lookup dictionaries, and API cache structures.

## 5. How do we build with it?
```js
Using Map classes in JS to store complex keys connections.
```

- **Expected Output**: Enables fast key-value lookups with non-string keys.
- **Best Practice / Rule**: JavaScript Maps preserve key insertion order, whereas standard Objects do not.
