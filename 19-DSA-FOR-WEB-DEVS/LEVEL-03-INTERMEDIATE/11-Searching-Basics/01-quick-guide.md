# Searching Basics

## 1. What is it?
Searching is the process of locating a target value within a data collection.

## 2. Why do we use it?
To retrieve target values from datasets, using Binary Search to find items in sorted arrays in fast O(log N) logarithmic time.

## 3. How does it work?
- **Analogy**: Searching a list. Linear Search checks one by one. Binary Search splits a pre-sorted phonebook page-by-page (checking left/right).
- **Mechanism**: The feature parses inputs or operations synchronously or asynchronously, executing compiled instructions and returning output responses or state modifications.

## 4. Where is it used?
Auto-complete input dropdowns and index checks.

## 5. How do we build with it?
```js
Linear search checks every index; Binary search splits pre-sorted list in half recursively.
```

- **Expected Output**: Retrieves target elements from database datasets.
- **Best Practice / Rule**: Binary search is O(log N) fast but requires the array to be pre-sorted before querying.
