# Challenge Task: Search in Rotated Sorted Array

## Objective
Search rotated sorted lists in O(log N) logarithmic time using Binary Search.

## Challenge Instructions
1. Suppose an array sorted in ascending order is rotated at some pivot unknown to you beforehand (e.g. `[4, 5, 6, 7, 0, 1, 2]` instead of `[0, 1, 2, 4, 5, 6, 7]`).
2. Write a function `searchRotated(arr, target)` that finds the index of the target in this rotated sorted array. If the target is not in the array, return `-1`.
3. Your algorithm must run in **O(log N)** Time Complexity.
