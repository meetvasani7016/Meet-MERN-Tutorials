# Challenge Task: Merge Sort Implementation

## Objective
Sort arrays using the divide-and-conquer strategy in Merge Sort.

## Challenge Instructions
1. Write a function `mergeSort(arr)` that recursively splits an unsorted array of numbers in half, sorts each half, and merges them using a helper function `merge(leftArr, rightArr)`.
2. Implement both functions from scratch without using JS array sorting methods.
3. Test your algorithm with a scrambled array of numbers to verify it returns a sorted array.
4. Explain in comments the Time and Space Complexity differences between Merge Sort and Bubble Sort.
