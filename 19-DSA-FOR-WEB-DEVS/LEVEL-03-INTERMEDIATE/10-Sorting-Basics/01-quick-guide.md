# Sorting Basics

## 1. What is it?
Sorting is the process of arranging data in a specific order (ascending or descending).

## 2. Why do we use it?
To organize unstructured data lists logically, preparing arrays for search operations or sorted visual layouts.

## 3. How does it work?
- **Analogy**: Sorting playing cards in your hand. You compare cards, swap locations, and line them up from low to high.
- **Mechanism**: The feature parses inputs or operations synchronously or asynchronously, executing compiled instructions and returning output responses or state modifications.

## 4. Where is it used?
Sorting products by price ranges or blogs by publication dates.

## 5. How do we build with it?
```js
Arranging prices list from cheapest to most expensive.
```

- **Expected Output**: Orders raw query arrays systematically.
- **Best Practice / Rule**: JavaScript's default Array.prototype.sort() sorts elements alphabetically, not numerically! [10, 2].sort() is [10, 2] unless you use comparison helpers.
