# How to Ask Good Questions

## 1. What is it?
Asking structured, clear questions helps teammates diagnose your bugs and respect your effort.

## 2. Why do we use it?
To write structured help tickets detailing expected inputs, error stack traces, and solutions attempted so teammates can assist efficiently.

## 3. How does it work?
- **Analogy**: Visiting a doctor. You do not just call: 'I feel sick, fix me.' You describe symptoms, timeline, and treatments tried.
- **Mechanism**: The feature parses inputs or operations synchronously or asynchronously, executing compiled instructions and returning output responses or state modifications.

## 4. Where is it used?
Asking for help on Slack or online forums.

## 5. How do we build with it?
```json
Asking help by detailing: 1. Expected behavior, 2. Actual error trace, 3. Code snippet, 4. Fixes attempted.
```

- **Expected Output**: Reduces blocking time and improves team collaborations.
- **Best Practice / Rule**: Provide code snippets as searchable text or links, never send screenshots of code!
