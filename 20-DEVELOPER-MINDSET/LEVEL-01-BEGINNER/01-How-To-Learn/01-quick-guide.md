# How to Learn Programming

## 1. What is it?
Programming is not about memorizing syntax; it is about building mental models and active problem-solving.

## 2. Why do we use it?
To avoid passive watching and focus on active coding practice, building strong mental models and memory retention.

## 3. How does it work?
- **Analogy**: Learning to build furniture. You do not just read wood catalogs; you grab tools, cut wood, and build chairs.
- **Mechanism**: The feature parses inputs or operations synchronously or asynchronously, executing compiled instructions and returning output responses or state modifications.

## 4. Where is it used?
Acquiring new framework skills.

## 5. How do we build with it?
```json
Coding along with lessons, then building a custom project from scratch using the same concepts.
```

- **Expected Output**: Accelerates learning speeds and boosts skills retention.
- **Best Practice / Rule**: Active practice (coding on your own) beats passive consumption (watching videos) by 10x.
