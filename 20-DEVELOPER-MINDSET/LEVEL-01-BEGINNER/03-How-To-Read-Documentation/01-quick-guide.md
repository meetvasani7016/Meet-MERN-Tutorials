# How to Read Documentation

## 1. What is it?
Documentation is the official user manual for a library, technology, or programming language.

## 2. Why do we use it?
To search official API guides and usage pages directly, eliminating dependence on outdated third-party tutorials.

## 3. How does it work?
- **Analogy**: Reading a lego assembly manual. You scan parts lists, look at diagrams, and follow sequence instructions.
- **Mechanism**: The feature parses inputs or operations synchronously or asynchronously, executing compiled instructions and returning output responses or state modifications.

## 4. Where is it used?
Onboarding onto new packages and coding SDKs.

## 5. How do we build with it?
```json
Going directly to the MDN reference site to check parameter definitions for Array.prototype.reduce().
```

- **Expected Output**: Builds independence, enabling you to learn new technologies without video guides.
- **Best Practice / Rule**: Never rely purely on third-party tutorials. Technology documentation is the single source of truth.
