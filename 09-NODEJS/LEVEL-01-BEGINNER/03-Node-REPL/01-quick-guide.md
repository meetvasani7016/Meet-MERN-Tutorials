# Node REPL

## 1. What is it?
REPL (Read-Eval-Print-Loop) is an interactive terminal shell for running JavaScript code on the fly.

## 2. Why do we use it?
To quickly test JavaScript statements, debug expression evaluations, or play with core Node APIs on the fly without creating a physical script file.

## 3. How does it work?
- **Analogy**: A calculator command line. You type JavaScript statements, it evaluates them, prints outcomes, and loops back.
- **Mechanism**: The feature parses inputs or operations synchronously or asynchronously, executing compiled instructions and returning output responses or state modifications.

## 4. Where is it used?
Testing code math, checking environment values, and validating small scripts.

## 5. How do we build with it?
```sh
Type 'node' in terminal to open prompt.
```

- **Expected Output**: Opens an interactive JavaScript console prompt.
- **Best Practice / Rule**: Press Ctrl+C twice or type '.exit' to close the REPL.
