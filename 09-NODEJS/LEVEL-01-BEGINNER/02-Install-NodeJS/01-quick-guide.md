# Install NodeJS

## 1. What is it?
Install the Node.js LTS (Long Term Support) runtime to compile and run local backend JS programs.

## 2. Why do we use it?
To write and execute JavaScript backend programs locally. Node.js comes bundled with npm (Node Package Manager), which is the gateway to installing millions of open-source packages.

## 3. How does it work?
- **Analogy**: Plugging a power engine into your computer's terminal, enabling command line tools to read and run JS code files.
- **Mechanism**: The feature parses inputs or operations synchronously or asynchronously, executing compiled instructions and returning output responses or state modifications.

## 4. Where is it used?
Every backend developer machine and CI/CD deployment server.

## 5. How do we build with it?
```sh
node --version
```

- **Expected Output**: Prints the installed version (e.g. v20.12.2).
- **Best Practice / Rule**: Always download the LTS version for local stability.
