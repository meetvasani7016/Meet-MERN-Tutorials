# GitHub CheatSheet

## In One Line
Print-friendly, compact reference for remote repository tracking, cloning, pulling, and push commands.

## Think Like This
Look once, remember forever: remote origin bindings, pull requests, and forks logs.

## Example
```sh
git remote add origin <url> -> connects local folder to cloud repository.
```

## Result
Speeds up remote repository synchronizations.

## Remember
Run git pull before pushing code to avoid merge conflicts with team updates.
