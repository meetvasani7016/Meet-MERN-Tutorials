# Summary: CSS CheatSheet

Here is a quick cheat sheet of what we covered in this lesson:

* Box Model: width, height, margin, padding, border, box-sizing.
* Flexbox: flex-direction, justify-content, align-items, gap.
* Grid: grid-template-columns, grid-template-rows, grid-gap, grid-column.
* Positioning: static, relative, absolute, fixed, sticky.
