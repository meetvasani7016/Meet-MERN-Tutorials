# Forks

## In One Line
A fork is a personal cloud copy of another developer's GitHub repository.

## Think Like This
Making a photocopying run of a textbook. You own the copy (the fork) and can write inside it without altering the original author's textbook.

## Example
```sh
Click 'Fork' button on GitHub UI.
```

## Result
Creates a new repository link under your personal GitHub namespace dashboard.

## Remember
Forks allow you to safely experiment with codebases and suggest updates back to the owner.
