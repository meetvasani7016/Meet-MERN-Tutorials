# GitHub Pages

## In One Line
GitHub Pages is a free static website hosting service integrated directly into GitHub.

## Think Like This
Deploying your site live to the internet. Putting your portfolio painting in a public gallery window.

## Example
```sh
Enable GitHub Pages in Repository Settings.
```

## Result
Publishes your repository's HTML/CSS files to a live public URL: https://username.github.io/repo/.

## Remember
GitHub Pages only hosts static sites (HTML, CSS, JS). Databases or Node backends are not supported.
