# Portfolio Repository Project

## In One Line
Build a clean, static portfolio page containing your resume and host it live on GitHub Pages.

## Think Like This
Putting your professional resume in a glass display case on a busy city street so any passing client can review it.

## Example
```html
<h1>Jane Doe | Developer Portfolio</h1>
```

## Result
Deploys a responsive portfolio website.

## Remember
GitHub Pages hosts static html, css, and js files for free.
