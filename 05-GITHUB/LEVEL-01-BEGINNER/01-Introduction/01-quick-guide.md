# GitHub Introduction

## In One Line
GitHub is a cloud platform that hosts Git repositories for collaboration and version control.

## Think Like This
GitHub is cloud backup storage like Google Drive or Dropbox, but customized specifically for code developers.

## Example
```sh
View repository page URL on github.com
```

## Result
Shows the project codebase, commit history graph, and team updates.

## Remember
Git is the engine tool. GitHub is the parking lot website.
