# Clone Repository

## In One Line
Sync cloud repositories to your local computer.

## Think Like This
Tethering your computer to a cloud folder. Downloading the initial copy to local storage.

## Example
```sh
git clone git@github.com:user/project.git
```

## Result
Creates a folder copy and sets up origin remote hooks.

## Remember
Using SSH keys avoids password typing on clones, pushes, and pulls.
