# Summary: JavaScript Functions

Here is a quick cheat sheet of what we covered in this lesson:

* Declaration: named function that can be called anywhere in the file (hoisted).
* Expression: function stored in a variable, cannot be called before definition.
* Arrow Function: ES6 syntax shortcut, does not bind its own 'this' context.
* Default Parameters: assigns values to inputs if they are omitted.
* Callback Functions: functions passed as input arguments to other functions.
