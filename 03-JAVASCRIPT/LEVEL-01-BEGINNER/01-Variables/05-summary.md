# Summary: JavaScript Variables

Here is a quick cheat sheet of what we covered in this lesson:

* Variables are defined using const, let, or var.
* const: block-scoped, cannot be reassigned or redeclared.
* let: block-scoped, can be reassigned but not redeclared.
* var: legacy, function-scoped, hoisted, can be reassigned and redeclared.
* Hoisting: JavaScript moves declarations to the top of their scope before execution.
