# JavaScript Variables

## In One Line
Variables are named containers used to store data values in memory.

## Think Like This
Cardboard boxes in a storage room with sticky labels on them.

## Example
```js
let price = 19.99;
const tax = 0.05;
var name = 'John';
```

## Result
Creates a changeable price variable, a read-only tax constant, and a legacy function-scoped name variable.

## Remember
Prefer const for all values that shouldn't change. Use let only when values must be reassigned. Avoid var!
