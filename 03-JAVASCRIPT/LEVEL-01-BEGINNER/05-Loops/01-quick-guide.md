# JavaScript Loops

## In One Line
Loops execute a block of code repeatedly while a specified condition is met.

## Think Like This
A music player set to 'repeat' mode, looping a playlist until you manually press stop.

## Example
```js
for (let i = 0; i < 3; i++) {
  console.log(i);
}
```

## Result
Prints 0, 1, and 2 in the console logs.

## Remember
Always ensure your loop variable updates so the test condition eventually fails, avoiding infinite loops!
