# JavaScript Conditions

## In One Line
Conditions control execution flow by running different code blocks based on truth tests.

## Think Like This
A railway switch board that routes a train down different tracks depending on a lever position.

## Example
```js
if (score >= 90) {
  console.log('A');
} else {
  console.log('B');
}
```

## Result
Prints 'A' if score is 90 or more, otherwise prints 'B'.

## Remember
Truthy values are evaluated as true. Falsy values (false, 0, '', null, undefined, NaN) evaluate to false.
