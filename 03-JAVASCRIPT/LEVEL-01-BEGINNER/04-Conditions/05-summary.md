# Summary: JavaScript Conditions

Here is a quick cheat sheet of what we covered in this lesson:

* if statement: checks a condition and runs a block if true.
* else if: checks alternative conditions sequentially.
* else: fallback block if all preceding conditions are false.
* switch: clean alternative for matching a single variable against multiple exact values.
* Falsy values: false, 0, '' (empty string), null, undefined, NaN.
