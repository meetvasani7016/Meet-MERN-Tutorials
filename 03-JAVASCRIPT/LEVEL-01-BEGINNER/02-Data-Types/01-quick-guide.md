# JavaScript Data Types

## In One Line
Data types define the kind of value stored in a variable (e.g. text, numbers, lists).

## Think Like This
Sorting recycling materials: plastic containers (strings) vs metal cans (numbers) vs switches (booleans).

## Example
```js
let username = 'Meet';
let age = 21;
let isInstructor = true;
let details = null;
let status = undefined;
```

## Result
Defines variables of types String, Number, Boolean, Null, and Undefined.

## Remember
Primitives are stored directly by value (immutable). Objects/Arrays are stored by reference (mutable).
