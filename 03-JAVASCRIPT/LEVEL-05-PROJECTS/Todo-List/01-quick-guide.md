# Todo List

## In One Line
A Todo List app adds and removes list items dynamically based on inputs.

## Think Like This
A notebook checklist page. You write items on blank lines, and cross them off when completed.

## Example
```javascript
let li = document.createElement('li');
li.innerText = 'New Task';
list.appendChild(li);
```

## Result
Adds a new bullet task item on your webpage.

## Remember
`document.createElement` constructs new HTML tags in memory, and `appendChild` inserts them.
