# Weather Widget

## In One Line
A weather widget simulates requesting forecasts for specific cities.

## Think Like This
Asking a local tourist booth agent (mock database) what the weather is like in Paris, rather than flying there to check.

## Example
```javascript
let mockDB = { 'paris': '20C' };
console.log(mockDB['paris']);
```

## Result
Prints '20C'.

## Remember
Mock datasets are essential for testing code layouts when external APIs are unavailable.
