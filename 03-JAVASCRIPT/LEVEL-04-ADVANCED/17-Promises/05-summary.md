# Summary: JavaScript Promises

Here is a quick cheat sheet of what we covered in this lesson:

* States: Pending (waiting), Fulfilled/Resolved (success), Rejected (failed).
* resolve(): function called when async task completes successfully.
* reject(): function called when async task encounters an error.
* Chaining: then() returns another promise, allowing sequential async steps.
* Promise.all(): runs multiple promises in parallel, resolving only when all complete.
