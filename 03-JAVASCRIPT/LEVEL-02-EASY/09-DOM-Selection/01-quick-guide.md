# DOM Selection

## In One Line
DOM Selection allows JavaScript to target and fetch HTML tags from a webpage.

## Think Like This
Using a laser pointer to point out specific picture frames hanging on a gallery wall.

## Example
```html
let title = document.getElementById('main-title');
```

## Result
Selects and references the HTML tag containing id='main-title'.

## Remember
querySelector returns only the FIRST matching element. querySelectorAll returns a list of ALL matches.
