# JavaScript Objects

## In One Line
Objects store key-value collections representing structured records.

## Think Like This
A filing cabinet folder. Instead of indexes, items are labeled: 'Name: Jane', 'Age: 25', 'Job: Designer'.

## Example
```js
let user = { name: 'Meet', age: 21 };
console.log(user.name);
```

## Result
Creates a user object and prints the value corresponding to the name key ('Meet').

## Remember
Use dot notation (obj.name) normally. Use bracket notation (obj['name']) when key is a dynamic variable.
