# Summary: JavaScript Objects

Here is a quick cheat sheet of what we covered in this lesson:

* Properties: key-value matches inside curly braces: { key: value }.
* Notation: dot notation (obj.key) and bracket notation (obj["key"]).
* Methods: functions stored as object properties.
* 'this' keyword: refers to the current parent object executing the method.
* Iteration keys: Object.keys(), Object.values(), Object.entries() return array listings.
