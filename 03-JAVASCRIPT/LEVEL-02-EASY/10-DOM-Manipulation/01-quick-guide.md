# DOM Manipulation

## In One Line
DOM Manipulation updates text, styles, classes, and structures on webpage elements.

## Think Like This
Painting your cardboard box a new color, rewriting its label, or adding new slots to it.

## Example
```html
element.innerText = 'Updated';
element.style.color = 'blue';
```

## Result
Updates the text of the selected element to 'Updated' and changes its text color to blue.

## Remember
Use classList.add() and classList.remove() to control styles instead of writing individual element.style lines.
