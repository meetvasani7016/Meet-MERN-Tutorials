# Summary: JavaScript Arrays

Here is a quick cheat sheet of what we covered in this lesson:

* Declaration: created using square brackets: [...].
* Insertion/Deletion: push() (end), pop() (end), shift() (front), unshift() (front).
* Utility methods: slice() (extracts parts), splice() (adds/removes anywhere), includes() (searches).
* High-Order Iteration: forEach() (loop), map() (transform), filter() (filter items), reduce() (aggregate).
