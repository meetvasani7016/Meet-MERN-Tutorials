# JavaScript Arrays

## In One Line
Arrays are ordered list variables used to store multiple values in a single container.

## Think Like This
A school locker corridor. Each door has an index number label on it (0, 1, 2...) containing books.

## Example
```js
let list = ['Apples', 'Milk'];
list.push('Eggs');
```

## Result
Creates a two-item array list, and appends 'Eggs' at index 2.

## Remember
Array index numbers are zero-based! The first item is at [0] and the last is at [array.length - 1].
