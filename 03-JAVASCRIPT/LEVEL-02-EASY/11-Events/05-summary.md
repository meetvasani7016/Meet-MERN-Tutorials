# Summary: JavaScript Events

Here is a quick cheat sheet of what we covered in this lesson:

* Event Listener: addEventListener('eventName', callbackFunction).
* Common Events: click, submit (form), keyup (keyboard), change (inputs).
* Event Object (e): carries details like clicked target (e.target) or key pressed (e.key).
* preventDefault(): halts default browser reactions (like link jumps or page refreshes).
