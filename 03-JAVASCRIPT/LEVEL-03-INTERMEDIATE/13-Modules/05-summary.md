# Summary: JavaScript Modules

Here is a quick cheat sheet of what we covered in this lesson:

* Export types: Named Exports (multiple per file) and Default Exports (one per file).
* Import format: import { name } from './file.js' for named; import name from './file.js' for default.
* Alias imports: use 'as' to rename imports (e.g. import { add as sum }).
* Root imports: import * as alias from 'path'.
