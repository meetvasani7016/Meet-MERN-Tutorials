# Summary: ES6 Features

Here is a quick cheat sheet of what we covered in this lesson:

* Arrow Functions: shorthand parameter syntax.
* Template Literals: backtick strings allowing multiline formatting and variable insertions.
* Destructuring: unpack values from arrays or object keys easily.
* Spread/Rest Operator (...): spreads arrays/objects or gathers arguments.
* Optional Chaining (?.): reads deep nested properties without crash errors if parent keys are missing.
