# ES6 Features

## In One Line
ES6 refers to modern JavaScript updates that make code cleaner and more expressive.

## Think Like This
Upgrading a bicycle to an electric scooter. It accomplishes the same task but is faster and requires less manual pedaling.

## Example
```js
const { name } = user;
const text = `Hi ${name}`;
```

## Result
Destructures user name and uses a template literal backtick string.

## Remember
Template literal backticks (`` ` ``) allow you to interpolate variables inside ${} without using + operators.
