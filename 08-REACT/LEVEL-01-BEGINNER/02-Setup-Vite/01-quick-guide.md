# Vite React Setup

## In One Line
Vite is a fast build tool used to scaffold and run modern React applications.

## Think Like This
Scaffolding a house framework: creating folders for blueprints (src), assets, and tool sets (npm) ready to develop.

## Example
```sh
npm create vite@latest my-app -- --template react
```

## Result
Creates a pre-configured React project directory.

## Remember
Vite uses native ES modules to compile code in milliseconds, making save-reloads extremely fast.
