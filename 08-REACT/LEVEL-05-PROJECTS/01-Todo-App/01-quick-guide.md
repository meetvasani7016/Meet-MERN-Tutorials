# React Todo App

## In One Line
Build a task manager application that stores todos in state, allows adding/removal, and saves data to localStorage.

## Think Like This
A sticky note checkboard. You write tasks, stick them on the board, check them off, and save them in a notebook so they stay there when you wake up.

## Example
```jsx
const [todos, setTodos] = useState([]);
```

## Result
Renders an interactive task manager.

## Remember
Always pass clean callback functions to mutate state arrays cleanly.
