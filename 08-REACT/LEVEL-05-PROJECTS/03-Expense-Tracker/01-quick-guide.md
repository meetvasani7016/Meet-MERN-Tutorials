# React Expense Tracker

## In One Line
Create a budget tracker calculating total incomes, costs, and display dynamic balances.

## Think Like This
A bank cash register: you catalog cash additions (incomes) and cost subtractions (expenses), calculating sums automatically on screen.

## Example
```jsx
const total = transactions.reduce((acc, t) => acc + t.amount, 0);
```

## Result
Renders budgets sheets.

## Remember
Array.reduce is the standard JavaScript method used to sum values in object arrays.
