# React Custom Hooks

## In One Line
Extract component states logic into reusable custom JavaScript functions.

## Think Like This
Creating a pre-wired security module. You install it in different houses; they all check alarms identical but operate independent.

## Example
```jsx
function useToggle(init) { ... return [val, toggle]; }
```

## Result
Provides reusable custom hook blueprints for components.

## Remember
Custom hook function names must always begin with the word 'use' (e.g. useFetch, useToggle).
