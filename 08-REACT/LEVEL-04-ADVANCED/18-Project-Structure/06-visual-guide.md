# Visual Guide: React Project Structure

```text

src/
├── assets/      (Images, fonts, stylesheets)
├── components/  (Reusable UI inputs, buttons, cards)
├── pages/       (Routing pages: Home, Dashboard)
├── hooks/       (Custom React hooks)
├── context/     (Global Context API providers)
├── services/    (Network api fetch scripts)
└── utils/       (Helper formatting scripts)

```
