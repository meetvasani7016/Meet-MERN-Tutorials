# First Repository Project

## In One Line
Initialize a repository, stage index and style files, write a commit, and look at the history graph logs.

## Think Like This
Taking snapshots of your bedroom as you clean it up: start tracking, pick items to clean, take the photo, inspect your photo album.

## Example
```bash
git init
git add .
git commit -m "First save"
git log --oneline
```

## Result
Initializes, stages, saves, and prints the save log.

## Remember
You must stage files before they can be committed to repository memory.
