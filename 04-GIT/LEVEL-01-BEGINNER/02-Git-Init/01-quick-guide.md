# Git Init

## In One Line
git init creates a hidden .git repository folder to start tracking a project.

## Think Like This
Turning on a security surveillance camera system in a building. From that moment, every movement in that room is recorded.

## Example
```sh
git init
```

## Result
Prints 'Initialized empty Git repository in /path/to/project/.git/'.

## Remember
Only run git init ONCE per project. Running it creates the hidden .git directory.
