# Git Add

## In One Line
git add copies file snapshots from your working directory to the staging area.

## Think Like This
Placing items into a shipping box. They aren't sent (committed) yet, but they are packed and taped ready to go.

## Example
```sh
git add index.html
```

## Result
Moves selected files from untracked/modified to staged (green status).

## Remember
Staging allows you to selectively choose which code edits to include in your next commit save.
