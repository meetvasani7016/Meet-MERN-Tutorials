# Git Introduction

## In One Line
Git is a version control system that tracks changes in your code files over time.

## Think Like This
A video game save-point system. If you fight a boss (write code) and fail, you can load your last save point (commit) instead of starting the whole game from scratch.

## Example
```sh
git --version
```

## Result
Prints the installed Git version (e.g., git version 2.45.0.windows.1).

## Remember
Git is local to your computer. GitHub is a cloud storage website that hosts Git repositories.
