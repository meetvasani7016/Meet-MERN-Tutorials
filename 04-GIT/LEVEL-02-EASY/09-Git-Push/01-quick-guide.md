# Git Push

## In One Line
git push uploads your local commits to a remote repository on the cloud.

## Think Like This
Posting a draft document to a team folder. Now your local saves are backup-saved in the cloud for everyone to see.

## Example
```sh
git push origin main
```

## Result
Uploads local commit history references and updates the cloud branch pointer.

## Remember
You can only push commits. Staged files or untracked changes will not be uploaded.
