# Git Conflict Resolution

## In One Line
Conflict resolution is the manual repair of overlapping file changes made by different branches.

## Think Like This
Two editors updating the exact same sentence in a document at the same time. The manager (you) must choose which version to keep.

## Example
```sh
Open a file showing conflict markers (<<<<<<<, =======, >>>>>>>) and edit manually.
```

## Result
Cleans up the code markers and completes the merge with a commit save.

## Remember
Conflict markers show: Current change (your active branch) vs Incoming change (the branch being merged).
