# Git Merge

## In One Line
git merge integrates commit history from one branch into another.

## Think Like This
Pouring tributary water back into the main river channel, combining all branch changes.

## Example
```sh
git merge feature-login
```

## Result
Joins the branch history, creating a merge commit or performing a fast-forward step.

## Remember
You must checkout to the branch you want to merge into (usually main) before running git merge.
