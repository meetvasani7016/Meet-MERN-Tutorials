# Git Branches

## In One Line
Branches create parallel sandbox timelines for adding features without affecting stable code.

## Think Like This
Creating a multiverse timeline copy of your city. You build a new bridge in the copy; if it works, you merge it with the main timeline.

## Example
```sh
git checkout -b feature-darkmode
```

## Result
Switches active developer files to a parallel workspace.

## Remember
The default main branch should always contain clean, working, deployable code.
