# Resume Guide

## 1. What is it?
How to structure a professional developer resume that passes applicant tracking systems (ATS) and catches recruiters' attention.

## 2. Why do we use it?
To structure technical expertise, projects metrics, and work achievements into a clean single-page format optimized for recruiting tracking systems (ATS).

## 3. How does it work?
- **Analogy**: A structured JSON document. Your resume should be clean, parsing-friendly, and list clear technical impacts.
- **Mechanism**: The feature parses inputs or operations synchronously or asynchronously, executing compiled instructions and returning output responses or state modifications.

## 4. Where is it used?
Job applications and hiring rounds.

## 5. How do we build with it?
```json
Structuring: Contact Info -> Skills List -> Projects -> Work History -> Education.
```

- **Expected Output**: Prepares an ATS-optimized, high-impact resume.
- **Best Practice / Rule**: Never list skills on a 1-to-10 scale (e.g. 'JavaScript: 8/10')—it is subjective and looks unprofessional.
