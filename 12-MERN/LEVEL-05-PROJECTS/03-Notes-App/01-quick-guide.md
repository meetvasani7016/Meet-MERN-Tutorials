# MERN Notes App Project

## 1. What is it?
Build a markdown notes compiler application mapping text inputs to MongoDB collections via Express APIs.

## 2. Why do we use it?
Developers use MERN Notes App Project to add structured logic, simplify code implementations, and resolve standard architecture requirements when building full-stack applications.

## 3. How does it work?
- **Analogy**: A cloud diary. You write notes locally, they are formatted in markdown visual windows, and saved permanently in cloud archives.
- **Mechanism**: The feature parses inputs or operations synchronously or asynchronously, executing compiled instructions and returning output responses or state modifications.

## 4. Where is it used?
Used across web applications, server scripts, and backend database integrations.

## 5. How do we build with it?
```javascript
const res = await fetch('/api/notes', { method: 'POST' });
```

- **Expected Output**: Builds full-stack note grids.
- **Best Practice / Rule**: Using search filtering on database queries reduces network bandwidth by only fetching target match results.
