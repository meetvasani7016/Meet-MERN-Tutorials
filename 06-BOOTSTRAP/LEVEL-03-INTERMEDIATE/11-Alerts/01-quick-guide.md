# Bootstrap Alerts

## In One Line
Contextual feedback messages for user actions with dismissal triggers.

## Think Like This
Colored sticky banners at the top of a page: yellow for warnings, red for errors, green for success updates.

## Example
```html
<div class="alert alert-success">Success!</div>
```

## Result
Displays a green notification banner with padding and matching text color.

## Remember
Add class .alert-dismissible to let the user close the alert.
