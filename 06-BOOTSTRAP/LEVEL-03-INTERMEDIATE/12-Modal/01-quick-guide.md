# Bootstrap Modal

## In One Line
Overlay dialogues that block background page interactions until dismissed.

## Think Like This
A pop-up login form box that darkens the background screen, forcing you to input or close it.

## Example
```html
<div class="modal fade" id="myModal">...</div>
```

## Result
Creates a hidden modal wrapper that overlays the page when triggered by a button.

## Remember
The button trigger needs data-bs-toggle='modal' and data-bs-target='#id' attributes.
