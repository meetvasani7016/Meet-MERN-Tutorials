# Bootstrap Carousel

## In One Line
A slideshow component for cycling through images or text slides.

## Think Like This
A rotating billboard that automatically slides to the next advertisement slide every few seconds.

## Example
```html
<div class="carousel slide" data-bs-ride="carousel">...</div>
```

## Result
Creates an interactive slideshow player with control arrows.

## Remember
Ensure images inside the slides use the class .w-100 to scale correctly across viewports.
