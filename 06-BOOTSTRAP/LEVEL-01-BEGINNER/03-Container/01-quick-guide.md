# Bootstrap Container

## In One Line
Containers are the basic layout element required to contain, pad, and align content.

## Think Like This
Margins on a notebook paper that keep you from writing too close to the left and right edges.

## Example
```html
<div class="container">Content</div>
```

## Result
Pads and centers the content box horizontally with responsive breakpoints.

## Remember
Use .container for a responsive fixed width, and .container-fluid for full width.
