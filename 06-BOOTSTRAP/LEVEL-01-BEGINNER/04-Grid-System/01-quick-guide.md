# Bootstrap Grid System

## In One Line
A 12-column responsive layout engine based on Flexbox.

## Think Like This
Dividing a cake into 12 equal slices. You can give one person 6 slices (half the screen), and another 3 slices (one-fourth).

## Example
```html
<div class="row"><div class="col-6">Left</div><div class="col-6">Right</div></div>
```

## Result
Creates a two-column row with equal widths.

## Remember
Columns must be placed inside rows, which must be placed inside containers.
