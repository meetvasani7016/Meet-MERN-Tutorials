# Bootstrap Installation

## In One Line
Install Bootstrap using a CDN link in the head, or npm package manager for production.

## Think Like This
Linking to a shared online library (CDN) vs downloading the books onto your computer (NPM).

## Example
```html
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
```

## Result
Imports all Bootstrap styles and components.

## Remember
Include both the CSS link in the <head> and the JS bundle script at the end of the <body> for interactive components.
