# Bootstrap Customization

## In One Line
Overriding Bootstrap default colors and styles using custom variables or Sass imports.

## Think Like This
Painting over the factory paint job of your car with a custom color scheme to fit your branding.

## Example
```html
$primary: #8a2be2; @import "bootstrap";
```

## Result
Compiles custom Sass to override Bootstrap utility colors.

## Remember
You can also customize Bootstrap color variables locally in CSS using Root variables.
