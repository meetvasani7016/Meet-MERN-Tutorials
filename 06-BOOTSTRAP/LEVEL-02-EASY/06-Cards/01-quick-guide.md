# Bootstrap Cards

## In One Line
A flexible, extensible content container with headers, footers, and images.

## Think Like This
A physical recipe card or ID card grouping name, photo, and bio neatly on one sheet.

## Example
```html
<div class="card"><div class="card-body">Hello</div></div>
```

## Result
Creates a beautiful content container with borders and drop-shadow styling.

## Remember
Cards fit perfectly inside Grid columns for building dashboard grids.
