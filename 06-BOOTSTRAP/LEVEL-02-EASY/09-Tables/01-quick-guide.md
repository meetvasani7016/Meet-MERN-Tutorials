# Bootstrap Tables

## In One Line
Grid table layouts styled with colors, stripes, borders, and hover states.

## Think Like This
An office ledger or spreadsheet that is structured with clean horizontal borders and highlighted rows.

## Example
```html
<table class="table table-striped table-hover">...</table>
```

## Result
Formatted data grid that highlights rows when hovered.

## Remember
Wrap your tables in .table-responsive to enable side scrolling on mobile screens.
