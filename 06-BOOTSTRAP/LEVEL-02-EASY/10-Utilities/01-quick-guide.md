# Bootstrap Utilities

## In One Line
Shorthand utility classes for spacing, borders, display, colors, and shadows.

## Think Like This
Quick styling labels like 'small margin', 'make text red', or 'add a shadow' that you stick onto element boxes.

## Example
```html
<div class="m-3 p-2 bg-dark text-white shadow">Utility Box</div>
```

## Result
Applies margin, padding, dark background, white text, and a drop shadow.

## Remember
Margin is m-, padding is p-. Axes: x for horizontal, y for vertical, t/b/s/e for top/bottom/start/end.
