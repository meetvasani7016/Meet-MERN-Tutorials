# Bootstrap Navbar

## In One Line
A responsive navigation header with branding, navigation links, and dropdown togglers.

## Think Like This
A map directory header at the top of a webpage, directing users to different pages on any screen size.

## Example
```html
<nav class="navbar navbar-expand-lg bg-light">...</nav>
```

## Result
Responsive top-bar navigation that collapses into a hamburger icon on mobile.

## Remember
Include the Bootstrap JS bundle for the hamburger dropdown to toggle open/close on mobile.
