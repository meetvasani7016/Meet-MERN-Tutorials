# Bootstrap Forms

## In One Line
Input controls styled for labels, sizes, states, and form groups.

## Think Like This
A digital clipboard questionnaire with uniform margins, focus outlines, and validation feedback.

## Example
```html
<input class="form-control" type="text" placeholder="Name">
```

## Result
Custom themed form input box with outline focus rings.

## Remember
Wrap labels and controls in elements with the .mb-3 class for consistent spacing.
