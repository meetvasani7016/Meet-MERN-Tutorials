# HTML SEO Basics

## In One Line
SEO tags inside <head> help search engines index and rank your webpage.

## Think Like This
SEO is the sign, menu, and address registration you post on a city street to invite customers to your restaurant.

## Example
```html
<title>Learn HTML | MeetTutorials</title>
<meta name="description" content="Simple tutorials.">
```

## Result
Google displays your title and description in search results.

## Remember
Keep title length under 60 characters so Google doesn't cut it off.
