# HTML Accessibility

## In One Line
Accessibility (a11y) ensures your website is usable by everyone, including disabled users.

## Think Like This
a11y is adding a smooth ramp next to the library stairs so visitors using wheelchairs can enter easily.

## Example
```html
<label for="name">Name:</label>
<input type="text" id="name">
```

## Result
Screen readers read the input description out loud to visually impaired users.

## Remember
Always define `<html lang="en">` and write alt descriptions on images.
