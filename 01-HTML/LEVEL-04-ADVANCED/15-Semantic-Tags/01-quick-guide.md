# HTML Semantic Tags

## In One Line
Semantic tags describe their structural meaning (<header>, <nav>, <main>, <footer>).

## Think Like This
Semantic tags are labeled folders in a filing cabinet.

Instead of stuffing all papers into generic white envelopes (<div>), you use folders clearly marked 'Recipes' (<article>) or 'Finances' (<aside>).

## Example
```html
<header>
  <nav>Links</nav>
</header>
<main>
  <article>Content</article>
</main>
```

## Result
Organizes the code visually and structurally for browsers and screen readers.

## Remember
Semantic layout helps search engine indexers (SEO) and screen readers (Accessibility) read your page.
