# HTML Tables

## In One Line
Tables (<table>) display grid data in rows and columns.

## Think Like This
Tables are like your school class timetable.

- Columns represent days.
- Rows represent class periods.
- Each cell represents a subject.

## Example
```html
<table>
  <tr><th>Subject</th></tr>
  <tr><td>Math</td></tr>
</table>
```

## Result
Displays a neat data grid.

## Remember
Never use tables to layout page designs! Only use tables to display grid data.
