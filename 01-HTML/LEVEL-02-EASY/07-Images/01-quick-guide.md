# HTML Images

## In One Line
Images (<img>) display pictures on a webpage.

## Think Like This
The <img> tag is a picture frame.

- The 'src' attribute is the string tied to the frame pointing to where the canvas painting is stored.
- The 'alt' attribute is the description card underneath the frame for blind visitors.

## Example
```html
<img src="cat.jpg" alt="A cute orange cat sleeping">
```

## Result
Renders the picture on the page.

## Remember
The <img> tag is self-closing—it does not need a closing </img> tag.
