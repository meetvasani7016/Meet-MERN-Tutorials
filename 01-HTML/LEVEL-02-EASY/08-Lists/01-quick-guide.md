# HTML Lists

## In One Line
Lists group related items. Use <ul> for bullets and <ol> for numbers.

## Think Like This
Lists are notebook entries.

- Unordered (<ul>) is a grocery list: order doesn't matter (eggs before milk is fine).
- Ordered (<ol>) is recipe steps: order is critical (mix before baking).

## Example
```html
<ul>
  <li>Apples</li>
  <li>Milk</li>
</ul>
```

## Result
Displays bullet points:
* Apples
* Milk

## Remember
Only list items (<li>) should be placed directly inside <ul> or <ol> containers.
