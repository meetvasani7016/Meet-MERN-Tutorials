# HTML Links

## In One Line
Links (<a>) are hyperlinks that connect webpages together.

## Think Like This
Links are teleportation doors.

You walk up to the door, read the sign (clickable link text), step through, and instantly arrive in a new room (href destination URL).

## Example
```html
<a href="https://google.com" target="_blank">Google</a>
```

## Result
Renders a clickable link pointing to Google that opens in a new tab.

## Remember
Always include the protocol (https://) for external URLs, otherwise the browser thinks it's a file on your computer!
