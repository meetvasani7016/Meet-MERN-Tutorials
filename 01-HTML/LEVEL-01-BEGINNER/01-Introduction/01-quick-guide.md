# HTML Introduction

## In One Line
HTML is the language used to create the structure of a web page.

## Think Like This
HTML is the skeleton of a human body.

Without a skeleton, the body has no shape.

Without HTML, a website has no structure.

## Example
```html
<h1>Hello World</h1>
```

## Result
Displays a large heading:

Hello World

## Remember
HTML = Structure
CSS = Design
JavaScript = Behavior
