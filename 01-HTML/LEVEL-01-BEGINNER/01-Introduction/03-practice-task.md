# Practice Task: HTML Introduction

## Objective
Apply what you've learned in this lesson by completing a basic exercise.

## Step-by-Step Instructions
1. Create a blank file named `my-first-page.html`.
2. Write the standard HTML skeleton.
3. Inside the `<body>`, write an `<h1>` tag with your name.
4. Open this file in your browser to see your name in giant, bold letters!
