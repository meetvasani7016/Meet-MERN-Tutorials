# HTML Comments

## In One Line
Comments allow developers to write notes in source code that the browser ignores.

## Think Like This
Comments are sticky notes inside a chef's cookbook.

The customer eating the food (the website visitor) never sees them, but the kitchen staff (developers) do.

## Example
```html
<!-- Remember to fix this header later -->
```

## Result
Displays absolutely nothing on the screen.

## Remember
Comments are NOT secure! Anyone can see them by right-clicking and viewing page source.
