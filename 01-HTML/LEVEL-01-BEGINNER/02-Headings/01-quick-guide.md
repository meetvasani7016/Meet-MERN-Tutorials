# HTML Headings

## In One Line
Headings (H1 to H6) are used to define titles and subtitles on a webpage.

## Think Like This
Headings are newspaper headlines.

- The H1 tag is the main front-page headline (use only one per page).
- The H2 and H3 tags are secondary article headers.
- H6 is the smallest footnote.

## Example
```html
<h1>Main Title</h1>
<h2>Sub-heading</h2>
```

## Result
Displays bold headings of decreasing sizes.

## Remember
Use headings to build page structure, not just to make text look big! Use CSS for sizing.
