# HTML Paragraphs

## In One Line
Paragraphs (<p>) represent blocks of text and automatically add spacing above and below.

## Think Like This
Paragraphs are like breathing breaks for your eyes in a storybook.

Instead of one giant block of endless text, paragraphs divide thoughts into clean chunks.

## Example
```html
<p>This is a paragraph.</p>
<p>This is another paragraph.</p>
```

## Result
Displays two separate blocks of text with empty space in between.

## Remember
Browsers collapse multiple spaces and enters inside a <p> tag. Use <br> to break lines.
