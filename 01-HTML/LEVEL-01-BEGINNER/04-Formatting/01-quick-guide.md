# HTML Formatting

## In One Line
Formatting tags alter the appearance and importance of text (bold, italics, highlights).

## Think Like This
Bold (<strong>) is like using a thick black marker.

Italic (<em>) is like speaking in an emphasized tone.

Mark (<mark>) is like using a yellow highlighter.

## Example
```html
<strong>Bold</strong>, <em>Italics</em>, and <mark>Highlight</mark>
```

## Result
Displays formatted text with physical style differences.

## Remember
Use <strong> and <em> (semantic tags) instead of <b> and <i> (visual tags) for better accessibility.
