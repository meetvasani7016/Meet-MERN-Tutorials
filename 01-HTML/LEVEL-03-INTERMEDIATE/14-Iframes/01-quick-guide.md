# HTML Iframes

## In One Line
Iframes (<iframe>) embed another webpage inside your current webpage.

## Think Like This
An iframe is a picture frame on your desk that is actually a portal window showing another entire room in another building.

## Example
```html
<iframe src="https://wikipedia.org" width="500" height="300"></iframe>
```

## Result
Displays Wikipedia in a frame box inside your webpage.

## Remember
Many large sites (like Google and Facebook) block iframes for security, rendering connection errors.
