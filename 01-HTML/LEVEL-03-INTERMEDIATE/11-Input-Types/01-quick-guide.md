# HTML Input Types

## In One Line
Input Types define what kind of input box to render (text, password, dates, checkboxes).

## Think Like This
Input types are specialized slots in a vending machine.

- The coin slot only accepts coins.
- The bill slot only accepts paper notes.
- The card slot only reads cards.

## Example
```html
<input type="password">
<input type="checkbox">
```

## Result
Renders a hidden password text field and a clickable checkbox.

## Remember
Always group related radio buttons using the exact same 'name' attribute so only one can be selected.
